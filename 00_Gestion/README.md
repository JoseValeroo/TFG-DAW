# Gestión del Proyecto

Esta carpeta contiene toda la documentación de gestión y organización del proyecto.

---

## Contenido

### Configuración del Proyecto
- **config_proyecto.json** - Configuración central del proyecto
- **CHECKLIST_INICIO.md** - Lista de tareas al iniciar proyecto

### Reuniones
Subcarpeta: `Reuniones/`
- Actas de reuniones con cliente
- Transcripciones de Teams
- Notas de seguimiento

### Requerimientos
Subcarpeta: `Requerimientos/`
- Documento de requerimientos funcionales
- Historias de usuario
- Casos de uso

### Planificación
Subcarpeta: `Planificacion/`
- Cronogramas
- Estimaciones
- Hitos del proyecto

---

## Inicio Rápido

### Pasos al iniciar un nuevo proyecto:

1. **Editar config_proyecto.json**
   - Actualizar nombre, equipo, tecnologías

2. **Completar CHECKLIST_INICIO.md**
   - Revisar todas las tareas
   - Marcar como completadas

3. **Crear estructura de reuniones**
   ```bash
   mkdir -p Reuniones/2025-01
   ```

4. **Documentar requerimientos**
   - Usar plantilla en `Requerimientos/PLANTILLA_REQUERIMIENTOS.md`

---

## Plantillas Disponibles

- `Reuniones/PLANTILLA_ACTA_REUNION.md` - Para documentar reuniones
- `Requerimientos/PLANTILLA_REQUERIMIENTOS.md` - Para especificar requerimientos
