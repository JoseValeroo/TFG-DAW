M Modos de Operacion

El comportamiento de Claude cambia segun el modo configurado en ESTADO_PROYECTO.json

puesta_a_punto

Proyecto nuevo incorporandose. Claude no modifica codigo, solo hace preguntas con /onboarding.

desarrollo

Desarrollo activo. Claude lee contexto, hace preguntas proactivas, implementa y documenta.

mantenimiento

Solo correcciones. Modo conservador, cambios minimos, siempre verifica tests.

soporte_uap

En produccion. Consulta runbooks, prioriza resolucion rapida, documenta incidencias.

Preguntas Proactivas por Situacion

Entendimiento

  • ¿Cual es el objetivo de negocio de esta funcionalidad?
  • ¿Quien es el usuario final?
  • ¿Es parte de un desarrollo mayor o es independiente?

Ubicacion

  • ¿En que modulo deberia ubicarse?
  • ¿Sigue el patron de alguna funcionalidad existente?

Datos

  • ¿Requiere nuevas tablas o modificacion de existentes?
  • ¿Maneja datos sensibles (personales, economicos)?

Seguridad

  • ¿Que roles/permisos tendran acceso?

Contexto

  • ¿Hay decisiones previas sobre esta funcionalidad que deba respetar?
  • ¿Hubo problemas anteriores con esta area del codigo?

Impacto

  • He detectado dependencias con [X,Y,Z]. ¿Quieres que analice el impacto?
  • ¿Hay tests existentes que deba conocer?

Integraciones

  • ¿Esta funcionalidad se integra con sistemas externos?
  • ¿Hay procesos batch o jobs que dependan de esto?

Reproduccion

  • ¿Puedes indicarme los pasos para reproducir el error?
  • ¿En que entorno ocurre (dev, staging, produccion)?

Urgencia

  • ¿Cual es la severidad? (critica, alta, media, baja)
  • ¿Hay workaround temporal?

Origen

  • ¿Cuando empezo a fallar? ¿Hubo cambios recientes?
  • ¿Afecta a todos los usuarios o solo a algunos?

Informacion General (Fase 1)

  • ¿Cual es el nombre oficial del proyecto?
  • ¿Quien es el owner (departamento propietario)?
  • ¿Quien es el jefe de proyecto (JP)?
  • ¿Quien es el lider tecnico (LT)?
  • ¿Quien es el responsable tecnico (RT)?

Stack Tecnologico (Fase 2)

  • ¿Que version de .NET se usa?
  • ¿Que framework web y ORM?
  • ¿Que motor de base de datos?

Equipo y Escalado (Fase 8)

  • ¿Quienes son los desarrolladores del equipo?
  • ¿Contacto de escalado tecnico?
  • ¿Contacto de escalado funcional?
  • ¿Hay bugs conocidos o deuda tecnica?
